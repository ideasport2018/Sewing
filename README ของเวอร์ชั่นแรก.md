# บันทึกการเย็บประจำวัน ปี 2569 (เวอร์ชัน Google Sheets + Apps Script)

ข้อมูลเก็บในไฟล์ Google Sheets ของคุณเอง ใช้งานผ่านหน้าเว็บที่ Apps Script เปิดให้ ไม่มีค่าใช้จ่าย

## ติดตั้ง (ครั้งเดียว ประมาณ 10 นาที)

1. สร้าง Google Sheets ใหม่ ตั้งชื่ออะไรก็ได้ เช่น "บันทึกการเย็บ (ฐานข้อมูล)"
2. เมนู **ส่วนขยาย > Apps Script**
3. ลบโค้ดเดิมในไฟล์ `Code.gs` แล้ววางโค้ดจากไฟล์ `Code.gs` ที่ให้ไป
4. ที่บรรทัดบนสุด ใส่ PIN สองบรรทัด
   - `SETUP_OWNER_PIN` = PIN เจ้าของ (แนะนำตัวเลข 6 หลัก)
   - `SETUP_STAFF_PIN` = PIN พนักงาน (ต้องไม่ซ้ำกัน)
5. กดปุ่ม **+** ข้าง "ไฟล์" > **HTML** ตั้งชื่อว่า `Index` (ไม่ต้องพิมพ์ .html) แล้ววางโค้ดจากไฟล์ `Index.html`
6. เลือกฟังก์ชัน `setup` ในแถบด้านบน กด **เรียกใช้** และอนุญาตสิทธิ์
   - ถ้าขึ้นหน้า "Google ยังไม่ได้ตรวจสอบแอปนี้" ให้กด ขั้นสูง > ไปที่ ... (ไม่ปลอดภัย) > อนุญาต (เป็นสคริปต์ของคุณเอง)
   - หลังรันเสร็จ ชีตจะมี 3 แท็บ: รายการ, รายวัน, ตั้งค่า
   - จะลบ PIN ออกจากโค้ดหลังรันแล้วก็ได้ ระบบเก็บเป็นค่าเข้ารหัสไว้แล้ว
7. กด **การทำให้ใช้งานได้ (Deploy) > การทำให้ใช้งานได้รายการใหม่ > Web app**
   - เรียกใช้ในฐานะ: **ฉัน**
   - ผู้มีสิทธิ์เข้าถึง: **ทุกคน**
   - กด Deploy แล้วคัดลอก URL
8. เปิด URL ใส่ PIN เจ้าของ ไปที่ **ตั้งค่า / สำรองข้อมูล > กู้ข้อมูลจากไฟล์สำรอง** แล้วเลือกไฟล์ .json ที่สำรองจากหน้าเว็บเวอร์ชันเดิม (ข้อมูล ประเภทเสื้อ ราคา แบรนด์ และรายชื่อพนักงานจะเข้าชีตทั้งหมด) การกู้ข้อมูลทำได้เฉพาะ PIN เจ้าของ
9. ส่ง URL + PIN พนักงานให้พนักงาน ให้เซฟเป็นบุ๊กมาร์กหรือเพิ่มไว้หน้าจอหลักมือถือ

## แก้โค้ดภายหลัง

หลังแก้ `Code.gs` หรือ `Index.html` ต้องกด Deploy > จัดการการทำให้ใช้งานได้ > ไอคอนดินสอ > เวอร์ชัน "เวอร์ชันใหม่" > Deploy URL จะเหมือนเดิม

## สิทธิ์การใช้งาน

| | เจ้าของ | พนักงาน |
|---|---|---|
| หน้าจดรายวัน (กรอก/แก้/ลบ ยอดหัก การมา-ขาด ยอดต่อคน) | ทุกวัน | เหมือนเจ้าของทุกอย่าง |
| สรุปรายเดือน/ปี | ครบทุกตาราง | เห็นเฉพาะ ยอดต่อคน และจำนวนตัวแยกตามแบรนด์ |
| ตั้งค่า สำรอง กู้ข้อมูล ส่งออก Excel | ได้ | ไม่มี (ฝั่งเซิร์ฟเวอร์ไม่รับคำสั่งตั้งค่าจากพนักงาน) |

หมายเหตุ: พนักงานเห็นยอดเงินในหน้าจดรายวันได้ตามสิทธิ์ใหม่ ส่วนการซ่อนยอดเงินในหน้าสรุปเป็นการซ่อนที่หน้าจอ

## ข้อควรรู้

- ใช้ PIN แทนบัญชี Google จึงไม่ต้องให้พนักงานมี Gmail แต่ระบบไม่รู้ว่าใครกรอก (ในชีตบันทึกแค่ว่า "owner" หรือ "staff") ถ้าอยากรู้รายคน ให้ตั้ง PIN ต่อคนในอนาคต
- ใส่ PIN ผิดครบ 8 ครั้งใน 10 นาที ระบบล็อกชั่วคราว (ล็อกทั้งระบบ) อย่าแชร์ URL ในที่สาธารณะ
- ห้ามแชร์ไฟล์ชีตให้พนักงาน ไม่เช่นนั้นเปิดดูยอดเงินในชีตได้
- แก้ข้อมูลในชีตตรง ๆ ได้ (แท็บ "รายการ") แล้วกดรีเฟรชในหน้าเว็บ แถวใหม่ที่ไม่มี id ระบบเติมให้เอง อย่าแก้คอลัมน์ id และคอลัมน์ "การมา-ขาด" แท็บ "รายวัน"
- คอลัมน์ "ยอด (บาท)" ในชีตคำนวณโดยระบบตอนบันทึก ถ้าแก้จำนวนหรือราคาในชีตเอง ยอดจะอัปเดตเมื่อแก้รายการนั้นจากหน้าเว็บอีกครั้ง
- การบันทึกแต่ละครั้งใช้เวลาราว 1–3 วินาที มีข้อความ "บันทึกแล้ว ✓" ที่แถบด้านบน ถ้าเน็ตหลุดระบบจะลองใหม่เอง อย่าปิดหน้าเว็บขณะขึ้น "กำลังบันทึก…"
- ถ้าเปิดสองเครื่องพร้อมกัน หน้าจะรีเฟรชข้อมูลเองทุก 2 นาที (ถ้าไม่ได้พิมพ์อยู่) หรือกด ↻ รีเฟรช
- ประวัติเวอร์ชันของชีต (ไฟล์ > ประวัติเวอร์ชัน) ช่วยย้อนข้อมูลได้ แต่ยังควรกดสำรอง .json เป็นระยะ
